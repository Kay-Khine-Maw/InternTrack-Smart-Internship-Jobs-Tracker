# Before/After Measurement Results

## Rules

- Use the same task, input, operator conditions and environment.
- Record the date, number of trials and raw values.
- Cite the command, session log or file behind every result.
- Never replace an unavailable measurement with an estimate.

## Current transcript evidence

The supplied U01–U05 transcripts provide qualitative post-test evidence, but no
task timestamps or completion records:

- Participants with supplied responses: 5/5.
- Participants reporting mostly trustworthy extraction while checking the
  original: 5/5.
- Participants reporting review or duplicate-warning value: 5/5.
- Participants reporting an improvement: 5/5.

Source: [interview-transcripts.md](../discover/interview-transcripts.md).

metrics.
