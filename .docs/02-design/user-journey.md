# InternTrack User Journey

## Overview

This document describes the primary user journey for a university student using InternTrack to manage internship applications. The journey is designed around a simple, repeatable cycle: discover an opportunity, capture the details, review the extraction, save the internship, and track the next action.

## Primary User Persona

### Student user

The main user is a university student who is applying to internships while balancing coursework, interviews, deadlines, and multiple opportunities at once. They need a lightweight system that helps them stay organized without manually copying information from many sources.

## User Journey: Add and Track a New Internship

### Stage 1: Start a new application

The student opens the dashboard and chooses to add a new internship.

At this point, the student may:

- paste a job URL
- upload a PDF, DOCX, PNG, or JPG file
- begin the intake process with a new opportunity

The goal is to move quickly from discovery to a saved record without excessive manual data entry.

### Stage 2: Extract the source details

The student submits the source content for processing.

The system then:

- reads the webpage or uploaded file
- extracts the raw text
- identifies the likely structured internship fields
- prepares the values for a review step

The student sees a data-filled form rather than a blank record, which reduces effort and keeps the process efficient.

### Stage 3: Review and correct the extracted content

The student reviews the generated record and validates the information.

This includes checking fields such as:

- company
- position title
- location
- application URL
- deadline
- skills or requirements
- notes and follow-up details

If something is missing or incorrect, the student can edit the field before saving.

This review step is essential because it guarantees the final record is accurate and aligned with the student’s actual application process.

### Stage 4: Save the internship

Once the extracted data is reviewed and corrected, the student saves the internship.

At this stage, the system stores the internship under the student’s record and makes it visible in the dashboard or list. The student can now manage it like other active applications.

### Stage 5: Manage application progress

After saving, the student updates the status over time.

Possible statuses include:

- saved
- preparing
- applied
- interview
- accepted
- rejected

The student can also track:

- priority level
- deadlines
- interview dates
- notes and preparation steps
- application documents and requirements

This stage turns the saved record into a working application tracker rather than a static note.

### Stage 6: View upcoming actions

The student uses the dashboard or calendar view to review what needs attention next.

This helps them answer questions like:

- Which applications are due soon?
- Which interviews are happening this week?
- Which roles need follow-up actions?
- Which internships are still in early preparation?

The calendar view adds a time-based planning layer that supports better prioritization.

## Secondary Journey: Revisit an Existing Application

A student may return to an existing internship record to:

- edit company or role details
- update the status
- add notes from a recruiter conversation
- mark a required document as complete
- review the next step in the process

This journey reinforces the product’s value as an operational system rather than just a one-time data capture tool.

## Journey Summary

The main experience follows this flow:

Discovery → Capture → Extract → Review → Save → Track → Follow up

This is the core value proposition of InternTrack: it converts the fragmented task of internship tracking into a structured, manageable workflow.

## Success Conditions

The user journey is considered successful when the student can:

- add an internship quickly
- rely on extraction to reduce manual input
- correct data confidently before saving
- track the process without losing context
- view upcoming tasks and decisions in one place

## Future Enhancements

As the product develops, this journey may expand to include:

- more advanced reminder flows
- richer analytics about application progress
- deeper profile-based personalization
- stronger integrations with university or career-service workflows

## Summary

InternTrack is built around the student’s real work pattern: discover opportunities, capture details, track decisions, and continue preparing for the next application. The user journey is intentionally simple, fast, and organized to fit the realities of internship searching.
