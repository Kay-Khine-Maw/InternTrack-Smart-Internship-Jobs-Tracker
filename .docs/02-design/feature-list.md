# InternTrack Feature List

## Product Summary

InternTrack is a university student internship tracker that helps users gather internship opportunities, extract the key details from job pages or uploaded documents, review the extracted data, and keep each application organized from initial interest to final result.

## Core Features

### 1. Internship Tracking

- Save internship opportunities in one place
- Track each role by status, deadline, and priority
- Maintain a consistent list of current applications
- View saved roles in a dashboard or list view

### 2. Add Internship Workflow

- Add an internship from a pasted URL
- Upload PDF, DOCX, PNG, or JPG files
- Trigger text extraction from the source material
- Review the extracted data before saving

### 3. AI-Assisted Extraction

- Extract job information automatically from public postings
- Parse documents and convert the content into structured fields
- Identify company, role, location, application link, and deadline
- Support AI-assisted translation for relevant fields

### 4. Review and Correction

- Inspect AI-generated values before saving
- Edit missing or incorrect fields manually
- Maintain control over final record quality
- Avoid blindly trusting automated field extraction

### 5. Application Status Management

- Mark internships as saved, preparing, applied, interviewing, accepted, or rejected
- Update progress as the application journey changes
- Keep decision and follow-up information attached to each record

### 6. Follow-Up and Timeline Tracking

- Record important dates and deadlines
- Track follow-up actions and reminders
- Maintain interview notes and preparation notes
- Centralize event-related planning in the application record

### 7. Document and Requirement Tracking

- Track required materials for each internship
- Use checklist-style tracking for application documents
- Record whether specific tasks or attachments are complete

### 8. Duplicate Detection

- Detect likely duplicate entries before saving a second identical internship
- Prevent redundant tracking of the same role
- Reduce noise in the internship list

### 9. Calendar Planning

- Show internship deadlines and follow-ups in a timeline view
- Help students see upcoming actions at a glance
- Support time management across multiple active applications

### 10. Profile Management

- Store user profile information for application context
- Support reusability across multiple internship records
- Keep personal information stored in a structured, central profile model

## User Value Features

### Faster intake

Students do not need to manually copy job details from a posting page into a spreadsheet or notes app. The system can extract much of the information automatically.

### Better organization

The dashboard and list view provide a single place to monitor multiple applications and their stages.

### Reduced risk of missing tasks

Deadlines, follow-up dates, and required documents are easier to keep visible when they are tied to each internship record.

### Improved review quality

AI extraction is useful, but the user still validates the result. This keeps the system useful and trustworthy.

## Feature Priorities

### Priority 1: Core workflow

- Add internship
- Extract data
- Review and correct
- Save internship record
- View and update status

### Priority 2: Planning and tracking

- Deadlines
- Interviews
- Follow-up reminders
- Notes and preparation details

### Priority 3: Enhancement features

- Duplicate warning flow
- Translation support
- Calendar visualization
- More advanced profile personalization

## Non-Goals in the Current Scope

The current product scope does not include:

- university authentication integration
- employer system integration
- public-facing internship marketplace features
- live production AI governance systems
- automatic deletion or retention pipeline beyond the current local implementation

## Summary

InternTrack’s feature set centers on a student-friendly internship-management workflow: capture, extract, review, save, and manage. The product is designed to reduce administrative overhead while keeping the student in control of each application decision.
