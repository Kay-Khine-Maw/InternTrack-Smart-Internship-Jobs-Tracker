# Data Sources and Permissions

## Product data

- Internship URLs and uploaded source content are supplied by the Student.
- Profile data is supplied or reviewed by the Student.
- Saved records belong to the authenticated Student.

## AI processing

Only the minimum necessary source content should be sent to the configured AI
provider. Do not send passwords, session tokens or unrelated profile data.

private documents and passwords. Secondary sources must include public URLs and
state what they do and do not prove.
